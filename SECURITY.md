# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in ValoraSec, please report it responsibly.

**Do not open a public issue.** Instead, email us at security@valorasec.dev (placeholder).

We will:

- Acknowledge your report within 48 hours
- Provide an estimated timeline for a fix
- Notify you when the fix is released
- Credit you in the release notes (with your permission)

## Supported Versions

| Version | Supported |
| ------- | --------- |
| 0.1.x   | ✅        |

## Security Best Practices

When using ValoraSec:

- Always use a strong JWT secret in production
- Keep dependencies updated
- Review generated audit reports before publishing
- Verify on-chain records independently
